# External audit, October 2026: findings and resolutions

An external audit of the release candidate (commit `3a9894d`) reported the
findings below. Each is resolved on the `gold-standard` branch; the commit
that resolves it is named.

| Finding | Resolution | Commit |
| --- | --- | --- |
| README and VISION said MPL-2.0; the cabal file and `LICENSE` say MIT. `LICENSE` held a template placeholder. | MIT everywhere; real copyright line; warranty-clause typo fixed. | `fix: release blockers` |
| CI failed `cabal check` on GHC 9.14.1 (`-O2` in the benchmark stanza), so the sdist and consumer steps never ran. | `-O2` removed (the scripts pass it to `cabal run`). | `fix: release blockers` |
| The weeder job failed. | It exited 4 because weeder skips the hidden `.hie` directory, and a shared `-hiedir` kept only one `Main.hie`. Fixed, one real finding removed, job made blocking, roots now cover everything `JsonLogic` exports, unused types checked too (ADR 0007). | `fix: release blockers`, `refactor!` |
| Lenient mode rejected `{"if":[true,1,{"*":[]}]}`, which the reference evaluates to `1`; the generator never produced an empty `*`. | Lenient keeps an empty `*`, which fails only if evaluated; 54 new outlier cases; the differential generator produces empty `*`. | `refactor!` |
| The community suite (1,138 cases) was never run. | Vendored, scored per file in both modes and pinned (ADR 0008); lenient scores exactly json-logic-js's 782; every rule is also an outlier case held to the reference. | `test: measure and pin the community suite` |
| `compile` only parsed; the evaluator was rebuilt on every `run`; custom operators were known only at run time. | `compile` takes the operators and builds the evaluator once; `run` only runs. | `refactor!` |
| About 3x slower than json-logic-js on 10,000-element `map`/`filter` (lists, numbers through `Rational`). | Vectors, Clinger's fast path, exact integer rounding, Ryū, compile-time `var` paths, one allocation per step: now in the same range as the reference in V8 (`map` 2.5 ms here vs 2.1 ms). | `refactor!` |
| Errors carried no location. | Every error carries the JSON Pointer of the failing node; tested to always resolve to the operator at fault (ADR 0006 closed). | `refactor!`, `test: every error location` |
| No static analysis of what a rule reads. | `dataUse`, scope-aware, with a tested guarantee. | `feat: dataUse` |
| The builtin operator names were written out four times. | One `Bounded` enumeration; every other list is derived. | `refactor!` |
| Stale design-session notes in the source (one said `undefined` maps to `null`). | Module and constructor documentation rewritten to state what the code does. | `refactor!` |
| `recursion-schemes` and Template Haskell for one fold and two instances. | `data-fix`'s `foldFix` and `unfoldFixM`; `Eq1`/`Show1` without Template Haskell (ADR 0002 superseded). | `refactor!` |

Also done while resolving them: CI on macOS and Windows; actionlint and
shellcheck on the workflows; the sdist verified with its Haddock (100%
coverage); `.gitattributes` for LF endings and untouched fixtures;
`lint.sh` usable off Linux x86_64; a tutorial whose every example is a test;
`docs/ARCHITECTURE.md`; and `docs/CONFORMANCE.md`, which documents the
fixtures for implementations in other languages.

Not done, by decision: the JSON Logic 2.0 dialect is measured, not
implemented (VISION.md §2, ADR 0008); custom operators stay eager, as the
reference's added operations are.
